# cmusic
CMusic is a standalone web-hosted music player intended to be an alternative to streaming platforms (e.g. Spotify, )

## Features
- Discord RPC, Last.FM support built-in
- Flexible plugin system that is easy to write for
- Lyrics (.lrc) support
- Transcoding support to Opus

## Contributing
- Feel free to make any pull requests! There is currently no CONTRIBUTING.md guidelines.

## Requirements
- Docker (Linux recommended)
